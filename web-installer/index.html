What is MoTLED?

MoTLED turns an ESP32-C6 into a smart LED controller using Matter over Thread. Control WS2812B, SK6812, and similar strips through Home Assistant, Apple Home, or Google Home.

Using MoTLED in Apple Home

Full guide: MoTLED User Guide covers setup, pairing, scenes and troubleshooting step by step.

Rename the tiles first. Home names extra tiles "Light 2", "Light 3"... in no particular order. Turn each on by itself to identify it: the main light (whole strip, your normal color), Color 1-4 (start red, green, blue, white) and the effect switches (rainbow, moving colors, sparkles). Press and hold a tile, tap the gear, and rename it.

  • Main light - the master: its power turns everything on or off and its brightness dims every mode.
  • Color 1-4 - turn on 2-4 for a multi-color pattern; all off returns to the main light's color. Their own brightness sliders are ignored.
  • Rainbow / Chase / Twinkle - add motion to whatever is showing; they combine.
  • Themes - save Home scenes like "Christmas" (red + green + Chase) and set the tiles you don't want to off.
  • Turning a feature checkbox on or off - remove the light in Home (with the board powered) and add it again.

Requirements

  • ESP32-C6 board with USB-C (e.g., DFRobot Beetle)
  • Addressable LEDs - WS2812B, WS2811, or SK6812
  • 5V power supply - ~60mA per LED at full white
  • Thread border router - HomePod Mini, Apple TV 4K, or SLZB-06
  • Matter controller - Home Assistant, Apple Home, Google Home

Configuration options

Number of LEDs - Total LEDs in your strip (1-1000)

GPIO pin - Data pin for the LED strip. GPIO 5 works on most ESP32-C6 boards.

LED type

  • WS2812B - Most common, 800kHz
  • WS2811 - Older, 400kHz
  • SK6812 - Similar to WS2812B, some have RGBW
  • WS2814 - RGBW, often 12V or 24V: choose SK6812 / WS2814 (RGBW) and usually a white-first order such as WRGB

Color order - If colors look wrong, try different orders:

  • GRB - Most WS2812B strips
  • RGB - Some WS2811 and older strips
  • BGR / RBG - Less common
  • WRGB etc. - RGBW strips that send white first (many WS2814)

Finding an RGBW order - Start with GRB, then set red, green, blue and white in your Home app and note which color each one shows. Whatever lights up for green is the strip's 1st byte, red its 2nd, blue its 3rd, and white its 4th. For example, if green shows white, red shows red, blue shows green and white shows blue, the order is WRGB.

Max Brightness - Limits power consumption and heat (1-255)

Device Name - One word, shown while pairing. Rename lights in your Home app afterwards.

After a power cut - Restore the last state, always turn on, or always stay off.

Color pattern lights - Adds Color 1-4 lights to your Home app. Turn on 2-4 of them to show a multi-color pattern (e.g. red and green); with all of them off the strip shows the main light's color. Each Color light is just on/off plus a color; the main light's brightness dims everything, and turning on a Color light also turns the main light on. Save Home scenes for your themes. Changing this checkbox needs a re-pair.

White only - For WS2805 strips (RGB + warm and cool white). The light shows in your Home app as a tunable white light: brightness plus warm-to-cool white, no color wheel. The color and effect extras are turned off. Changing this checkbox needs a re-pair.

Effect switches - Adds Rainbow, Chase and Twinkle on/off switches to your Home app. They combine and work on whatever is showing: Rainbow fills the strip with a rainbow, Chase makes the colors march along the strip, Twinkle adds random sparkles. The main light's brightness dims them, and turning one on also turns the main light on. Changing this checkbox needs a re-pair.

Color Pattern Layout / Band Size - Alternating bands of N pixels (like classic holiday bulbs), or equal blocks (halves, thirds, quarters).

Serial commands

help Show available commands

config Show current settings

set leds <n> Set LED count

set gpio <n> Set data pin

set type <type> ws2812b, ws2811, sk6812, ws2805

set bin <n|off> WS2805 backup data GPIO

set white_order <o> WS2805 whites: ww_cw, cw_ww

set order <order> grb, rgb, brg, rbg, bgr, gbr; RGBW: add w where white goes, e.g. wrgb

set brightness <n> Max brightness 1-255

set name <name> Device name (one word)

set poweron <m> After a power cut: restore, on, off

set color_lights <on|off> Color 1-4 lights in Home (needs re-pair)

set pattern_layout <l> alt or blocks

set pattern_group <n> Band size in pixels (1-255)

pattern <colors> Test 1-4 colors, e.g. pattern red green; pattern off (not saved)

set white_only <on|off> WS2805: tunable white only in Home (needs re-pair)

set effect_switches <on|off> Rainbow/Chase/Twinkle in Home (needs re-pair)

motion <m...> Test rainbow, chase, twinkle (any mix); motion off (not saved)

effect <name> Test rainbow, breathing, candle, chase; effect off (not saved)

pairing Show the pairing QR code (while not paired)

save Save config to flash and reboot

reboot Restart device

factory Erase all settings

Troubleshooting

Can't flash / No port selected

  • Use Chrome or Edge (Firefox doesn't support Web Serial)
  • Hold BOOT button while clicking Install
  • Try a different USB cable (some are charge-only)

Device boot loops

  • Flash failed mid-way - try flashing again

Can't find device during commissioning

  • Commission within 30s of boot (BLE advertising slows after)
  • If "Fabric already commissioned", run factory command
  • Ensure Thread border router is nearby

Wrong colors

  • Try different Color Order settings

LEDs don't light up

  • Check power - LEDs need 5V, not 3.3V
  • Verify GPIO pin matches wiring
  • Confirm LED count is correct
